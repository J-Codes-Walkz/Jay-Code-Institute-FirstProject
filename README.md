README — Learning To Code (One‑Page Website)
Project Overview
Learning To Code is a cohesive, accessible, one‑page website built using semantic HTML and modern CSS layout techniques. The goal is to provide beginners with a simple, structured introduction to HTML & CSS, while demonstrating responsive design, accessibility, and clean UI principles.
The site includes:
* A main navigation menu
* Four structured sections: Home, About, Services, Contact
* A responsive layout using Flexbox + Grid
* Aesthetic header imagery
* Accessible colour contrast and alt text
* A contact form with labelled inputs

Purpose of the Project
This is my first major project, designed to:
* Showcase the basics of HTML & CSS
* Demonstrate responsive design
* Provide resources for new learners
* Highlight accessibility best practices
* Build confidence using CodePen, VSCode, and GitHub
* Practice real‑world project documentation

Wireframe (Balsamiq)
* Header with navigation: Home / About / Services / Contact
* Hero section with H1 and introductory paragraph
* About section with H2 and descriptive text
* Services section with three blue boxes
* Contact section with Name / Email / Message fields
* Footer with copyright text

This wireframe guided the final layout and ensured the design remained simple, readable, and beginner‑friendly.
